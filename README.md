---

## ✨ Features

- **Zero Framework / Zero Build Step**: Pure semantic HTML5, modern CSS3 variables, and vanilla JavaScript.
- **Theme Persistence**: Light and dark mode with system preference auto-detection (`prefers-color-scheme`) and `localStorage` persistence.
- **Print & PDF Optimized**: Tailored `@media print` styling for clean, single/dual-page resume exporting via browser print dialog.
- **One-Click Interactions**: Click-to-copy email with toast feedback, quick links to GitHub & LinkedIn.
- **Rich Previews & SEO**:
  - Open Graph & Twitter Cards with branded vector preview banner (`og-image.svg`).
  - Google Structured Data (`schema.org/Person` JSON-LD).
  - Web App Manifest (`manifest.json`) and custom SVG favicon.
- **Automated Validation**: GitHub Actions workflow testing HTML markup compliance and manifest integrity.

- **Markup & Styling**: HTML5, CSS3 (CSS Variables, Flexbox, CSS Grid)
